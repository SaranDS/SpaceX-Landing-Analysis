# SpaceX-Landing-Analysis
This project applies machine learning techniques to predict whether the Falcon 9 first stage will land successfully after launch.

SpaceX significantly reduces launch costs (≈ $62M) compared to competitors (>$165M) by reusing the first stage. By accurately predicting landing outcomes, this project helps estimate launch cost efficiency and mission feasibility.

The workflow includes:

Data collection and preprocessing
Exploratory data analysis (EDA)
Feature engineering
Model training and evaluation
Prediction of landing success

This project is part of a capstone focused on real-world data science applications in the aerospace domain.
